# 📊 Análise de Vendas de uma Loja

Projeto de análise de dados desenvolvido em Python com Pandas e Matplotlib.

## 🎯 Objetivo

Analisar dados de vendas para identificar padrões de faturamento,
produtos mais vendidos, categorias de maior faturamento e formas
de pagamento mais utilizadas.

## 🛠️ Tecnologias utilizadas

- Python
- Pandas
- Matplotlib
- Google Colab
- Jupyter Notebook

## 📈 Análises realizadas

- Faturamento total
- Quantidade vendida por produto
- Faturamento por produto
- Faturamento por categoria
- Formas de pagamento
- Visualização dos dados através de gráficos
